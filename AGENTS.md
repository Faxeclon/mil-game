# Working agreement for coding agents

Before changing this project, read [PROJECT_SPEC.md](PROJECT_SPEC.md). It is the source of truth.

1. Preserve Spanish and English support and keep every child-facing string in message files, not TSX.
2. Do not collect personal data or add permissions, tracking, advertising, analytics, authentication, databases, or backend services without an explicit updated specification.
3. Add dependencies only for a justified requirement; preserve the existing package manager and current framework conventions.
4. Do not use copyrighted, branded, viral, franchise, emoji, or generic-robot mascot characters.
5. Keep game-domain logic outside route components and maintain the separation between media origin and information reliability.
6. Preserve semantic, keyboard-accessible, reduced-motion-aware, child-friendly accessibility foundations.
7. Do not implement planned future functionality prematurely or present mock functionality as operational.
8. Run lint, type checking, tests when available, and a production build. Report incomplete work and warnings honestly.
